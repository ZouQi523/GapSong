# GapSong · macOS 歌词悬浮窗 + 填空听写

[![Platform](https://img.shields.io/badge/platform-macOS%2015%2B-blue)](#系统要求)
[![Swift](https://img.shields.io/badge/Swift-5-orange)](https://swift.org)
[![License: GPL v3](https://img.shields.io/badge/license-GPLv3-blue)](LICENSE)

当前源码版本：**0.6.1**（构建号 **7**）。

把 Apple Music 的歌词变成能听、能填的英语练习：悬浮歌词同步滚动、端上翻译，喜欢的句子收进「收藏歌词」，答错的句子自动进「错题本」，按 30%–100% 的强度做填空听写。不注入、不修改 Apple Music 本体；翻译离线完成，收藏、错题和设置只存在本地。

> **Gap** 就是歌词里被挖掉的那个空：边听边填，填完接着唱。

## 系统要求

- macOS 15（Sequoia）或更高版本；
- 从源码构建需要 Xcode Command Line Tools：`xcode-select --install`；
- 首次运行需要授予「控制音乐」的自动化权限。

## 安装

当前先开放源码，尚未发布可下载的正式安装包。可按下面步骤自行构建；后续安装包会出现在 [Releases](https://github.com/ZouQi523/GapSong/releases)。

### 从源码构建

```bash
git clone https://github.com/ZouQi523/GapSong.git
cd GapSong
./build.sh                     # 产物在 build/GapSong.app
open build/GapSong.app         # 也可以拖进 /Applications

# 可选：连同安装到 /Applications
./build.sh --install
```

构建同时生成 `build/GapSong.zip`，内含已验证本地签名的应用。若工程位于云同步目录，建议从 ZIP 解压到「应用程序」后使用，避免同步服务附加的文件元数据影响签名。

> 默认按当前机器架构构建（Apple Silicon 得到 arm64，Intel Mac 上得到 x86_64）。通用二进制还在 Roadmap 里。

首次运行会依次请求两项系统权限：

| 权限 | 时机 | 位置 |
|---|---|---|
| 控制「音乐」 | 启动后第一次读取播放状态 | 系统设置 › 隐私与安全性 › 自动化 |
| 下载翻译语言包 | 播放第一首需要翻译的歌时，系统弹窗 | 点弹窗里的「下载」，等待完成 |

然后打开「音乐」播放任意歌曲即可。菜单栏有一个 ♪ 图标，所有开关都在那里（也可以右键歌词窗，或在窗口里按 `1` 打开键盘菜单）。

> 翻译语言包只需下载一次（按语言对，几百 MB）。下载期间歌词窗会显示「首次使用：请在系统弹窗中允许下载语言包…」。

> **从旧版 LyricFloat 升级**：GapSong 首次启动会自动迁移 `~/Library/Application Support/LyricFloat` 与 `~/Library/Caches/LyricFloat` 里的收藏（旧称题库）、翻译缓存，并沿用旧偏好。收藏文件仍是 `questions.json`，旧 ID/原文不变。因为 Bundle ID 改成了 `com.gapsong.app`，系统会重新询问一次「控制音乐」权限。

### 练习（听写）

1. 菜单栏 ♪ ›「开始练习（听写）…」，或右键歌词窗 › 同名菜单；也可以按 `1` 打开键盘菜单 › `1 练习`；里面直接有「练当前歌曲 / 练收藏歌词 / 练错题本」；
2. 菜单入口会先进入只含**填写比例**的设置页（来源随入口带入）：`2` 减少、`3` 增加比例，`4` 开始、`7` 返回、`1` 菜单；
3. 正常播放时，把窗口拉高到全文模式，点任意一句歌词右侧的 **书签** 就能收藏这一句（再点一次移除）；紧凑歌词窗和练习页不再放顶部收藏入口；
4. 不想开音乐时，从菜单选「练收藏歌词」或「练错题本」进入比例页，开始后会先暂停正在播放的音乐，每道题自动朗读当前句，判分、看答案、点词查义都照常；错题本还会显示每句的错误次数和上次错误。

## 功能

- **歌词自动匹配**：按「歌名 + 歌手 + 专辑 + 时长」查 LRCLIB（第三方歌词服务，提供 LRC 时间轴），失败再用搜索兜底；结果本地缓存 90 天。
- **逐行同步**：400ms 采样 Music 的播放位置并在本地插值，20fps 刷新，`[offset:]`、一行多时间戳、纯文本歌词都能处理。
- **端上翻译**：使用系统 `Translation.framework`，离线、不上传歌词。默认译为简体中文，可切繁中 / English / 日本語 / 한국어。
- **翻译缓存**：同一句只翻一次，跨歌曲、跨重启复用（`translations.json`）。
- **窗口可调**：拖右下角手柄自由缩放（歌词态最小 420×110，练习态最小 480×380，避免把答题区压没），或菜单「窗口大小」选紧凑 / 标准 / 大 / 宽屏；位置和尺寸都会记住，退出练习会回到进入前的歌词窗尺寸。
- **字号可调**：菜单「字号」里有 4 档预设，也能 ±2 连续放大缩小（14–72）；歌词窗和听写页正文都会跟着变（按钮、胶囊和间距仍只跟窗口缩放，窄窗里不会横向裁切）。练习各阶段和歌词窗都有 `⌘=` / `⌘-` 快捷键（`⌘⇧=` 与数字区 `+`/`-` 同样有效）。
- **背景透明度**：右键 ›「背景透明度」可选 不透明（默认，保持现有视觉）/ 15% / 30% / 45%；只让窗口背景真实透出，文字和按钮保持清晰，透明时叠一层系统材质，选项会记住。
- **全文模式**：窗口高度 ≥250 自动切到全文视图，可上下滚动看整首歌词（当前句高亮、**字号加大**，其余变暗、每句带译文）；手动滚动会暂停自动跟随 10 秒，点「↓ 回到当前」立刻归位。窗口缩回矮条则自动回到三行模式。
- **听写练习**：可以边听边填；所有被挖空的词都填对时，在真实句末自动进入下一句，没填全则唱到句末暂停等你答。给出按强度挖空的下划线与整句中文；`空格` 或点击横线切换当前空，跳过的空也能回头补；判分后逐词对照，可反复重听、随时看答案、点词查义，并累计积分与连对；音乐听不清时按 `8` 换成清晰的本地朗读。详见下方「练习模式」。
- **键盘优先**：按 `1` 打开窗口内数字菜单，显示/练习/收藏/强度/字号/窗口/翻译/退出等全部操作都能用 `1–9`/`0` 完成；菜单打开时练习数字键自动暂停，不需要右键或鼠标。
- **悬浮窗**：普通窗口层级，可被其它应用窗口正常覆盖；跨桌面与全屏 App 可见、显示/隐藏翻译、进度条。
- **拖动**：设置/答题/揭示/歌词（紧凑与全文）顶部都有一条 12pt 留白拖拽条，中间一道很短的小横线提示；只覆盖顶部窄带，不挡按钮、填空、滚动或右下角缩放手柄。拖动用事件自身位置计算、不依赖全局指针；App 不在最前时第一次点击即可拖动；锁定后不可移动，顶部也不显示抓手。
- **退出**：窗口左上角有 `×` 按钮，点一下直接退出；也可以右键 ›「退出 GapSong」或菜单栏 ♪ ›「退出」。
- **填空强度**：30%–100% 可选，按句内词位置稳定挖空（同一句每次都挖同样的词，不会打着字横线乱跳），练习中也能随时切换。
- **收藏歌词**：全文模式下每句右侧有书签，点一下收藏，提示会显示「已收藏 · 共 N 句」；紧凑歌词窗和练习页不再放顶部收藏按钮。数据仍在 `questions.json`，重启仍在，同一句不重复收藏。
- **收藏练习**：进入时不启动新音乐、并把正在播放的音乐暂停，从收藏随机出题；每道题自动朗读当前英文原句，答完可看答案、看错词对照、点词查义，收藏里的句子自带歌曲信息。
- **本地朗读**：用系统 `AVSpeechSynthesizer` 的实际英语音色朗读当前英文原句，语速按听写放慢，不联网、无外部依赖。收藏/错题练习里朗读就是「播放」：进入练习与每道新题（含「再试」）都会自动朗读；歌曲练习听不清时按 `8` 用清晰朗读替代音乐。再按一次停止；换题、重试、切来源、结束练习、退出都会取消旧朗读，不叠音。
- **错题本**：只有「真正提交且判错」才入库；跳过、空提交、只看答案、逐字红色提示、没填的空都不记。同一句合并成一条，保留每一次错误提交的完整历史。
- **错题练习**：进入时暂停正在播放的音乐，用本地朗读作为这一句的「播放」；顶部显示错题次数与上次错误，可看答案、再试、下一句；可用 `2` 朗读或停止当前英文原句，没有歌曲音频，也不提供重听。
- **直接入口与管理**：右键歌词窗和菜单栏都有「练当前歌曲 / 练收藏歌词（N）/ 练错题本（N）/ 查看收藏与错题」；空库入口仍显示但置灰并说明。管理窗口可查看、单句删除、从列表练一句或练全部；进入窗口自动暂停音乐、关闭恢复；清空需要二次确认。
- **零侵入**：不改 Apple Music、不录音频、不碰 DRM。

## 练习模式（听写）

用歌词练听力、拼写和回想：**选强度 → 听一句（或直接看题）→ 看中文回想英文 → 写下被挖空的词 → 逐词对照 → 点词查义**。

菜单栏 ♪ ›「开始练习（听写）…」，或右键歌词窗 › 同名菜单，或按 `1` 打开键盘菜单选择练习。开启时先进入设置页（窗口自动放大到适合答题的尺寸，退出时恢复到进入前的歌词窗尺寸，跨重启也记着）。

### 填写比例与题目来源

开始练习页只保留**填写比例**，来源由进入它的菜单入口决定：

- `2` 减少、`3` 增加：在 30%–100% 的预设档位间逐档调整，两端停住；`4` 开始、`7` 返回、`1` 菜单。
- 页面上只留一句「填写比例越高，难度越大」：比例越高，被挖掉的词越多；100% 就是整句听写。
- **题目来源在键盘菜单里选**：`1` 打开菜单 › `1 练习`，再按 `2 练当前歌曲` / `3 练收藏歌词` / `4 练错题本`；每个入口都会先进入比例页并把来源带进去。`1 开始练习（听写）` 用自动默认来源（有歌用歌，否则收藏，再否则错题）。
  - `当前歌曲`：用正在播放的歌，边听边填；全对到真实句末自动下一句，没填全才在句末暂停；听不清时按 `8` 换成清晰的本地朗读（会先暂停音乐，按 `2` 可回到音乐）；
  - `收藏歌词`：用你收藏过的句子出题，不启动新音乐并暂停正在播放的音乐，题目顺序随机，每道题自动朗读；
  - `错题本`：用本机错题本出题，同样先暂停音乐；本地朗读就是这一句的「播放」，没有音乐重听。

练习中右上角的「填空 xx%」可以随时改强度（当前这句立刻按新比例重挖，改完输入焦点会还给你）；按 `6` 返回设置页（保留当前来源），或按 `1` 打开菜单 › `1 练习` 换来源/强度。切换来源会先结束旧会话：停止歌曲计时、取消自动下一题，避免旧任务推进新题。

菜单 ›「练习选项」里还有 **「句末停得早/晚」**：默认延后 0.2s 再暂停，LRC 时间轴整体偏早或偏晚时可以在这里补偿（0.5s ~ 提前 0.1s）。**「打字机音效」** 在键盘菜单 › `1 练习` › `7 打字机音效` 和状态栏/右键菜单里切换：默认关闭，打开后每次真实输入一个英文字母轻响一次；声音在本地合成，不联网，粘贴、删除、空格和程序性同步不发声。

#### 播放出问题时不会假装正常

歌曲模式依赖「音乐」的播放状态。读不到状态、没拿到自动化权限、或者你自己按了暂停时，练习界面会直接说明原因，并保留你已经输入的答案：

- **手动暂停 / 播放状态停住 / 没有采样**：显示可读的原因与「重试播放 / 跳过 / 结束练习」；**不会自动恢复播放**，也不会把它当成「这句练完了」；
- **没有自动化权限**：额外提供「打开系统设置」直达 `隐私与安全性 › 自动化`；
- 异常恢复需要你主动点「重试播放」，不会擅自恢复手动暂停；点「结束练习」会如实写「练习提前结束」，不会冒充正常练完。

#### 收藏与错题保存失败会明说

收藏/错题写入失败（磁盘满、目录只读等）不会显示成「已收藏」：歌词窗、练习界面和管理窗口都会显示保存失败的原因，本次修改会回滚。读不出的 `questions.json` / `mistakes.json` 会先逐字节备份成 `*.corrupt-*.json` 再重建；连备份都做不了时会进入只读保护，宁可这次不写，也不覆盖原始文件。单条删除和批量清空都要二次确认，点「取消」不写任何文件。

### 收藏歌词与错题本

把窗口拉高到全文模式后，每一句歌词右侧都有一个 **书签**（鼠标移上去变亮）：

- 点一下收藏（变成实心），再点一次取消；收藏数据、管理窗口和逐句书签都保留；
- 收藏时连歌曲名、歌手、译文一起存下来，练习时不用重新匹配；
- 存在 `~/Library/Application Support/GapSong/questions.json`，重启仍在；同一首歌的同一句只存一次；
- 中文/日文等没有可听写字母的行，按钮是灰的；
- 紧凑歌词窗顶部和练习页右上角不再放收藏入口；需要收藏时把窗口拉高到全文模式，或从管理窗口查看已有收藏。

错题本与收藏完全分开，存在 `~/Library/Application Support/GapSong/mistakes.json`：

- 只在**真正提交且判错**时写入；逐字红色提示、跳过、空提交、只看答案都不算；
- 同一句按「歌手 + 歌名 + 原句」合并成一条，每次错误追加历史，不自动删除；
- 历史包含完整原句、当时译文、歌名歌手、句子时间、提交时间、题目来源、挖空比例、逐空位置/期望/实际、原始输入；
- 部分填空跳空后，跳过的空也会保留位置，错误位置仍能对上；
- 看答案后再试虽然不计分，但真正判错仍会记录；
- 答对不会删除旧记录；再次练错继续追加；
- 错题保存/读取失败会在管理窗口和练习界面显示警告；读不出的原始文件会先备份为 `mistakes.corrupt-*.json` 再写新文件，不会静默覆盖。

点菜单「查看收藏与错题…」打开管理窗口：进入时自动暂停正在播放的音乐（回看时不该有音乐盖着），关闭窗口恢复；列表显示原文、译文、歌名歌手，可单句删除（会先弹确认，点「取消」不写盘）；「练这句」只练一条，「练全部」练整个库，从窗口直接开始练习时暂停会交给练习会话、退出练习再恢复；错题行可展开查看每一次提交，历史不会自动删除。批量清空同样会弹二次确认。

### 流程（当前歌曲）

1. 从当前播放位置往后找第一句可练的歌词，跳到句首开始播放。
2. **播放时就可以填写**；已经填过的内容在句末暂停后继续保留，不会因为切到答题态被清空。
3. 画面给出整句中文 + 按强度挖空的下划线（每个下划线对应一个字母），没被挖的词直接露出来当提示。
4. **直接在横线上打字**：对的字母立刻变绿，错的变红，剩下的还是下划线；退格键可以改。单词之间的空格和标点不用打，判分也不计较（空格键用来切换空，不会输入空格）。
5. **填满当前空会自动跳到下一个空**；也可以按 `空格` 或点击任意横线切换当前空（当前空有一层浅底色）。空格会向前循环，走到最后一个空后回到第一个还没填的空；跳过的空、填了一半的空都能点击回去补。用户不必填满所有空。
6. **全对自动推进**：所有被挖空的词都有内容且整体判分正确时，如果这一句还没唱完，就等音乐真正到句末再切下一句（不暂停、不 seek、不截断歌曲）；如果句末已经停下来了，立刻进入下一句。部分正确、只填一部分、空提交、判错、看答案都不会自动通过。
7. 按 `Enter` 提交（答题底部只提示一句「回车继续」，不再放重复的提交按钮）：只判你真正填过的空，跳过的空不算错。答对显示原文 + 译文，1.8 秒后自动进入下一句。
8. 答错：横线上保留你的输入（红色标出听错的字母），可以继续改；也可以按 `2`（或 `⌘R`）反复重听这一句，次数不限，已输入的内容不会丢。如果音乐本身听不清（混响、连读、音量小），按 `8` 换成清晰的本地朗读：会先暂停音乐并回到当前句句首，`2` 仍可随时回到音乐播放。
9. `3`/「看答案」任何时候都能点；揭示后可以点任意单词查含义，也可以按 `3` 重新填这一句（不计分；歌曲来源会从当前句句首重新播放），或按 `4` 继续下一句。

### 流程（收藏歌词 / 错题本）

1. 从收藏或错题本随机取题，直接显示答题界面；进入时会暂停正在播放的音乐（只暂停、不新建播放），退出练习时按「我们按下的暂停」规则恢复；
2. 挖空比例、空格/点击切换横线、只填部分空、全对自动下一题、判分、看答案、点词查义都和「当前歌曲」一致；
3. 这两类练习把本地朗读当作「播放」：每进入一道新题（含看答案后的「再试」）都会自动朗读当前英文原句，朗读中再按 `2` 停止；歌曲来源没有的「重听」在这里由朗读替代；揭示后同样可以按 `3` 再试；
4. 错题本练习顶部有「错题 ×N」，并回看上次错误输入；管理窗口可展开全部历史；
5. 练完显示得分，并把「答对 N 句」与「答错 N 次（M 句）」分开写——同一句错两次是 2 次、1 句，不会说成「错了两句」；可以「再来一遍」（单句练习仍是同一句，整库练习重新打乱）或「重新选择」换强度。

**键盘操作**（不用鼠标也能全程使用）

| 按键 | 作用 |
|---|---|
| `1` | 打开键盘菜单（歌词态和练习态都可以）；菜单里 `1–9` 选当前页、`0`/`Esc` 返回或关闭 |
| `2` | 歌曲：重听这一句；收藏/错题：朗读当前英文原句（朗读中再按一次停止）；设置页：减少填写比例 |
| `8` | 歌曲：用清晰朗读替代听不清的音乐（朗读中再按一次停止）；收藏/错题不显示 |
| `3` | 看答案；揭示后为「再试一次」（不计分）；设置页：增加填写比例 |
| `4` | 当前主操作：设置开始、揭示下一句、结束再来一遍（答题提交只走回车） |
| `5` | 跳过这一句（答题/收听阶段） |
| `6` | 返回练习设置 |
| `7` | 退出练习回歌词（不退出 GapSong） |
| `⏎` | 答题提交；揭示后下一句；结束后再来一遍（设置页除外） |
| `空格` | 切到下一个空；到最后一个空后回到第一个未填的空（可循环） |
| 点击横线 | 直接选中任意一个空，回到前面补填/修改 |
| 打字 | 当前空填够该词的字母数后自动跳到下一个空 |
| `⌘V` | 粘贴到当前空（按逐空批量落字；不发声，不覆盖剪贴板） |
| `⌘R` / `⌘E` / `⌘T` / `⌘.` | 兼容旧快捷键：重听 / 看答案 / 再试 / 跳过 |
| `⌘=` / `⌘-` | 放大 / 缩小字号（每次 2pt，14–72；`⌘⇧=`、数字区 `+`/`-` 同样有效，练习各阶段和歌词窗都能用） |
| `Esc` | 菜单打开时返回/关闭；练习中（菜单关闭）兼容退出练习（等同 `7`） |

按钮上直接印着数字；答题阶段没有提交按钮，按 `⏎` 提交，底部只显示「回车继续」。数字只在 GapSong 自己的窗口内生效；带 `⌘`/`⌃`/`⌥`/`Shift` 的组合不触发，`9`/`0` 不会写进答案（菜单打开时 `0` 是返回）。当前阶段没有对应动作时，按键也会被消费，不会漏进填空题。

**键盘菜单（`1`）**

按 `1` 打开窗口内菜单，窗口会临时加高；菜单打开期间练习数字键全部暂停，数字只用于选项：

- `1–9`：选择当前页对应的项；子菜单再按数字继续下钻；
- `0` / `Esc`：返回上一级；在根菜单直接关闭；
- 其余按键（包括 `⌘V` / `⌘R` 等会打到菜单后面按钮的组合）不会漏进填空，也不会触发练习动作；`⌘=` / `⌘-` 改字号在菜单之前处理，仍然可用。

![键盘菜单](docs/screenshots/menu.png)

根菜单 9 项：练习、收藏与错题、外观、字号、窗口大小、翻译、歌词、显示/隐藏歌词窗、退出 GapSong（隐藏窗口刻意放在靠后，避免 `1 → 8` 误触后找不到窗口）。每页最多 9 项，不需要翻页——练习（开始/退出、练当前歌曲/收藏/错题（这三个入口先进入比例页）、填空强度、句末延迟、打字机音效、返回设置页）、收藏与错题（查看、清空）、外观（锁定、透明度、全文）、字号（4 档 + 放大/缩小）、窗口大小（4 档）、翻译（开关 + 5 种语言）、歌词（重新匹配、重试翻译、来源/状态）。每一项都带当前值（如「收藏 4 · 错题 3」「填空 60%」「字号 24」「LRCLIB」），全部操作不依赖鼠标；状态栏/右键菜单仍然保留。

> 菜单键在 GapSong 窗口获得键盘焦点时生效：练习窗进入时会自动聚焦；歌词窗点一下或拖动后即获得焦点，窗口隐藏时不会抢键。管理窗口里的列表操作仍以鼠标为主，练习可以从菜单直接进入。

> 练习窗采用应用内英文直输：即使系统当前是中文输入法，英文字母也会直接落进横线，不弹选字候选；`1` 是菜单键、`2`–`8` 是练习功能键。不会切换或修改 macOS 全局输入源，歌词窗与管理窗口仍正常使用系统输入法。隐藏的 AppKit 文本视图只负责粘贴与兜底，残留组字会在直输前清掉。

**朗读（收藏 / 错题 / 歌曲）**

朗读用 Apple `AVSpeechSynthesizer` 的实际英语音色读当前英文原句；语速按听写放慢，不联网、不依赖大模型或云 API。

- **收藏 / 错题**：朗读就是这两类练习的「播放」——进入练习、下一题、看答案后「再试」都会自动朗读当前句，答题与揭示页也可以点「2 朗读」手动重读，再按一次停止；
- **歌曲**：`2` 仍是重听音乐；听不清时点「8 朗读」或按 `8`，会先暂停音乐、回到当前句句首，再改用清晰朗读，此时仍可直接填写，`2` 可随时回到音乐播放；
- 两种模式都不会叠音：换题、重试、切来源、结束练习、退出练习都会取消旧朗读，也不会读上一题或自动计分；系统找不到英语音色时只提示「没有可用的英语语音」，不会静默改用中文音色。

**积分**

| 事件 | 分数 |
|---|---|
| 听对（填满） | +8 ~ +12（30% 强度 8 分，之后每档 +1，100% 12 分） |
| 只填了一部分 | 按“已填空数 / 总空数”折算基础分，最低 1 分；跳过的空不扣分，也不给分 |
| 连对第 2 / 3 / 4 句起 | 额外 +2 / +4 / +6 |
| 看答案、跳过、答错 | 0 分，连对清零（不扣分） |

重听不扣分——反复听是正常的学习方式，不该被惩罚。积分按每次练习累计；换歌、换来源或「再来一遍」会清零。

错误提交（真正按 `⏎` 且判错）会写进错题本，但不会额外扣分；错题练习本身仍按上面的积分规则计分。

**错题记录**

| 字段 | 内容 |
|---|---|
| 原句 / 译文 / 歌名歌手 / 句子时间 | 提交时的快照；译文缺失时显示翻译缓存里的结果 |
| 提交时间 / 题目来源 | 当前歌曲 / 收藏歌词 / 错题本 |
| 挖空比例 | 当次 30%–100% |
| 逐空 | 第几个空、原句词下标、期望词、实际填写、是否跳过；部分跳空仍能对齐 |
| 原始输入 | 输入缓冲；管理窗口同时给出按空分隔的可读摘要 |
| 次数 | 同一句合并，保留每一次；答对不删旧记录 |

**判分规则**（宽进严出）

| 情况 | 判定 |
|---|---|
| 大小写、标点、弯引号 | 忽略 |
| 空格与词界（整句连写 `morningfoundtheharborpaintedgold`） | 判对（横线着色本来就忽略空格） |
| 缩写漏撇号（`dont` / `don't`） | 判对 |
| 数字与英文（`4` / `four`） | 判对 |
| 换词、少字母（`word` / `world`） | 判错，逐格标红 |
| 只填了部分空（空格跳过） | 只判已填的空；跳过的空不算错 |
| 连字符（`all right` / `alright`） | 判错（是不同词） |

> 判分和横线着色共用同一个字符口径（`DictationJudge.comparisonChars`），
> 所以不会出现「满屏绿字却判错」。自检里有一条不变式在守这个约束：
> 逐格全绿 ⇒ 必然判对。

**会跳过哪些句子**（仅「当前歌曲」来源）

- 纯符号行（`♪`）、`Oh oh oh` 这类重复感叹
- 日文/中文/韩文行（拉丁字母占比 < 90%）
- 少于 3 个词、或只有 1 个不同词的行
- 与上一句完全相同的连续重复行
- 时长不足 1.2 秒的行

**字号与窗口**：听写界面的正文、填空横线、中文提示和逐词对照都跟菜单「字号」缩放（24 就是现在的默认排版，14–72 全程可调），同时整体仍随窗口大小等比缩放，拖大窗口字也会跟着变大。按钮、胶囊和间距只跟窗口缩放，大字号不会把它们挤出窄窗的左右边界；内容变高时练习页可以上下滚动，下方的操作按钮仍然够得到。改字号只重排版，当前题、已填答案、分数、播放进度和重试状态都不会被重置，也不会触发播放或改动窗口尺寸。下划线区整体居中，输入的文字直接落在下划线上。

**句末停在哪儿**

LRC 只标了每句的**开始**时间，所以「这句唱完」只能用下一句的开始时间近似。默认会在下一句开始后再放 **0.2 秒**才暂停——宁可多听半个音，也不要把这一句的尾巴切掉。

如果觉得还是切得早，或者反过来听到了下一句的开头，右键歌词窗 ›「句末停得早/晚」可以直接调，立即生效：

| 选项 | 含义 |
|---|---|
| 提前 0.1 / 0.2 s | 更早停（适合句间有明显空白、又不想听到下一句的歌） |
| 准时停 | 恰好停在下一句开头 |
| 延后 0.1 / 0.2 / 0.35 / 0.5 s | 更晚停（默认 0.2） |

这个值存在偏好里，之后一直沿用。

## 实现要点

| 环节 | 做法 |
|---|---|
| 读取播放状态 | AppleScript（`NSAppleScript`，独立串行队列，400ms 采样），`with timeout 4` 防卡 |
| 位置平滑 | 采样点 + 本地时钟插值，避免 0.4s 一跳 |
| 歌词源 | `https://lrclib.net/api/get` → 失败走 `/api/search`，按时长差排序挑最接近的版本 |
| 翻译 | SwiftUI `.translationTask(configuration)` 拿 `TranslationSession`，`translations(from:)` 批量翻；语言包未安装时系统自动弹下载确认 |
| 窗口 | `NSPanel`（`.borderless + .nonactivatingPanel`，`.normal` 普通层级，`.canJoinAllSpaces`），不强制置顶、可被其它应用窗口覆盖；歌词和练习页顶部使用 12pt 专用拖动条，不遮挡内容与按钮 |
| 听写控制 | AppleScript `pause` / `set player position` / `play`，与读取同属 `com.apple.Music.playback` 权限组，无需二次授权 |
| 填空 | `PracticeBlanks` 用文本 FNV-1a 哈希决定取词起点、等距选词：同一句每次都挖同样的位置，非拉丁行不挖空 |
| 收藏歌词 | `QuestionBank` 存 `~/Library/Application Support/GapSong/questions.json`，按「歌名 + 句子」去重（`GAPSONG_HOME` 可覆盖） |
| 错题本 | `MistakeBook` 存 `mistakes.json`；身份 = 歌手 + 歌名 + 原句，逐次追加历史，不推断掌握度、不自动删除 |
| 播放控制 | `PracticeEngine` 只依赖 `MusicControlling` 协议；自检/快照注入 `Spy`/`Noop`，绝不向真实 Music 发命令 |
| 隔离 | `AppRuntime` 为 `--selftest` / `--snapshot*` 提供临时数据目录与独立 `UserDefaults` suite，不写真实偏好 |

## 状态与排错

歌词窗右上角的小字是翻译状态：

| 状态 | 含义 |
|---|---|
| 准备翻译… | 已排队，等待系统翻译会话启动（正常只闪一下） |
| 首次使用：请在系统弹窗中允许下载语言包… | 需要你在系统弹窗点「下载」，最大等 180 秒 |
| 翻译中… N 行 | 正在逐批翻译（换歌会接着翻，不用重开） |
| 等待语言包就绪，20 秒后自动重试… | 上次被取消，会自动重试（最多 2 次） |
| 翻译未完成：… | 被取消/超时，右键 ›「重试翻译」 |
| （显示 LRCLIB） | 这首歌不需要翻译（中文歌译为中文）或翻译已完成 |

如果卡在「准备翻译…」，右键 ›「重试翻译」；仍不行就看 `~/Library/Caches/GapSong/diag.log`。

练习相关：收藏为空时「收藏歌词」菜单入口会置灰，先在全文模式下点歌词右侧书签；错题本为空时同理，必须先真正提交一个错误。开始练习页按 `2` / `3` 改填写比例；练习中右上角的「填空 xx%」也可以直接改强度，按 `6` 返回设置页，或从键盘菜单重新选来源。错题本读写失败时，管理窗口和练习界面会显示警告，不会假装保存成功。

## 隐私

- 不收集遥测或统计数据，没有账号，也没有自建服务器；
- 歌词匹配会把「歌名 / 歌手 / 专辑 / 时长」发给 [LRCLIB](https://lrclib.net)，这是应用主动发起的网络请求（结果本地缓存 90 天）；系统翻译语言包的首次下载由 macOS 处理；
- 翻译使用系统 `Translation.framework`，在本机完成，不上传歌词；
- 收藏、错题、设置、翻译缓存分别保存在 `~/Library/Application Support/GapSong` 和 `~/Library/Caches/GapSong`（收藏 `questions.json`、错题 `mistakes.json`）；
- 通过 AppleScript 读取/控制「音乐」的播放状态，不读取音频、不碰 DRM。

## 已知限制

- 歌词来自第三方库，冷门歌/现场版可能查不到；纯文本歌词没有时间轴，只显示前 4 行。
- 搜索兜底时会按时长挑版本，极端情况下可能匹配到翻唱或英文版。
- 翻译是系统模型逐句翻，质量中等；不结合整首上下文（可后续接 LLM 替换 `TranslationEngine`）。
- 依赖 macOS 15+（`Translation.framework` 的最低版本）。
- 只支持 macOS；iOS 端无法注入 Apple Music，只能做独立播放器 App（MusicKit + 自绘歌词页）或灵动岛 Live Activity 方案。
- 收藏歌词/错题本只练拉丁字母句子（英文等），中文/日文行收藏按钮会置灰；填空比例按「词数」取整，短句可能只挖 1 个词。
- 收藏/错题练习没有歌曲音频，不能重听；进入时会暂停正在播放的音乐并自动朗读每道新题，也可按 `2` 手动朗读或停止，退出时恢复我们暂停的音乐。错题历史只保存提交时的快照，不推断掌握度，也不会自动删除。
- 错题身份按「歌手 + 歌名 + 原句」；同名不同歌手的同一句会分开记录。
- 听写模式对时间轴精度比看歌词敏感得多：LRC 时间轴偏 0.5 秒，句末暂停就会切到下一句的开头。先用右键菜单里的「句末停得早/晚」补偿；如果整首歌都偏，说明歌词源本身不准。
- 每句的结束点是按「下一句的开始」推断的，没有上限。万一遇到两句之间是长间奏（十几秒），会等得比较久——按 `5` 跳过即可。
- 听写时每句都会抢一次键盘焦点（不然没法输入）。如果只是听歌，别开这个模式。
- Apple Music 不支持变速（脚本字典里没有播放速率属性），所以快歌只能靠重播，不能放慢。
- LRC 本身有错字时，听写会一直判错——先「看答案」跳过这一句。
- 点词释义用的是端上翻译引擎（本机没有装系统词典时 `DCSCopyTextDefinition` 返回空，所以没走词典路线）。它脱离上下文，多义词可能给的是最常见义项（比如 `rule` 会显示「规则」而不是「统治」）；句子整句译文就在上方，可以对照判断。
- 答题时显示中文会降低难度。如果只想练纯听力，把菜单里的「显示翻译」关掉即可。
